## 2. 总体结论

### 2.1 是否影响核心

结论是：**会触达核心边界，但没有修改核心业务处理算法。**

没有修改的核心链路：

- 设备遥测接收、转换和持久化逻辑；
- Actor 消息调度；
- 规则引擎节点执行逻辑；
- Kafka、Redis、Cassandra、PostgreSQL 的日常数据读写 DAO；
- 告警计算、设备连接会话和 Edge RPC 数据同步；
- 用户认证令牌生成和权限判定核心逻辑。

实际触达的核心边界：

- HTTP API 内容类型和浏览器安全响应头；
- TLS、证书、keystore 和 classpath 资源文件加载；
- PostgreSQL、Timescale、Cassandra 的安装或升级脚本；
- Edge 安装、升级说明生成；
- Trendz、通知、2FA 配置保存接口；
- Edge Markdown 展示。

## 4.1 全局 HTTP 安全头

文件：

`application/src/main/java/org/thingsboard/server/config/ThingsboardSecurityConfiguration.java`

```java

        .contentTypeOptions(config -> {})
        .cacheControl(config -> {})
```

影响：

建议验证：

```bash

curl -I https://实际地址/api/noauth/image/...
```

重点确认响应头和静态资源 MIME。

- `TelemetryController` 是核心 API 入口，因此这不是完全“零核心影响”；但本次没有改变任何遥测计算、查询参数、DAO 调用或返回数据结构。
- `RuleChainController` 只改变管理 API 响应声明，不改变规则链运行时。
- `EdgeController.findMissingToRelatedRuleChains` 返回 Java `String`，其内容实际是 JSON 字符串。现在 Content-Type 会明确为 JSON；读取字符串主体的现有 RestClient 通常仍能工作。

必须回归：

```bash

curl -H 'Accept: */*' ...
curl -H 'Accept: text/plain' ...
```

第三种请求预期可能返回 406，需要确认是否存在此类外部调用方。

## 4.4 公共安全路径组件

新增文件：

`common/data/src/main/java/org/thingsboard/server/common/data/util/SecurePathUtils.java`

### 配置路径规范化

```java
public static Path normalizeConfiguredPath(
        String configuredPath, String description) {
    if (configuredPath == null || configuredPath.isBlank()) {
        throw new IllegalArgumentException(
                description + " must not be blank");
    }
    validatePathText(configuredPath, description);
    Path path = Path.of(configuredPath);
    rejectParentSegments(path, description);
    return path.toAbsolutePath().normalize();
}
```

### 可信根目录内解析

```java
public static Path resolveUnderRoot(
        Path root, String... relativeParts) {
    Path normalizedRoot = root.toAbsolutePath().normalize();
    Path resolved = normalizedRoot;
    for (String relativePart : relativeParts) {
        Path part = Path.of(relativePart);
        if (part.isAbsolute()) {
            throw new IllegalArgumentException(
                    "Absolute child paths are not allowed: "
                            + relativePart);
        }
        rejectParentSegments(part, "Relative path part");
        resolved = resolved.resolve(part);
    }
    resolved = resolved.normalize();
    if (!resolved.startsWith(normalizedRoot)) {
        throw new IllegalArgumentException(
                "Resolved path escapes the trusted root: " + resolved);
    }
    verifyExistingPathRemainsUnderRoot(
            normalizedRoot, resolved);
    return resolved;
}
```

### 普通文件和可读性检查

```java
public static Path requireReadableRegularFile(
        Path path, String description) throws IOException {
    Path realPath = path.toRealPath();
    if (!Files.isRegularFile(
            realPath, LinkOption.NOFOLLOW_LINKS)
            || !Files.isReadable(realPath)) {
        throw new IOException(
                description
                        + " is not a readable regular file: "
                        + realPath);
    }
    return realPath;
}
```

### 软链接越界检查

```java
Path realRoot = root.toRealPath();
Path realResolved = resolved.toRealPath();
if (!realResolved.startsWith(realRoot)) {
    throw new IllegalArgumentException(
            "Resolved path escapes the trusted root "
                    + "through a symbolic link: " + resolved);
}
```

兼容性影响：

- 包含字面 `..` 的配置路径会被拒绝，即使规范化后仍指向合法位置。
- 配置成目录而不是文件会被拒绝。
- 不存在、不可读的文件会更早失败。
- 安装目录内部指向外部目录的软链接会被拒绝。
- 正常绝对路径可以使用；“根目录下的子路径”参数不允许绝对路径。
- 检查发生在启动、安装、升级或读取配置文件时，不在遥测消息热路径。

## 4.7 PostgreSQL 和 Timescale SQL 执行

### SqlAbstractDatabaseSchemaService

SQL 文件：

```java
Path schemaIdxFile =
        installScripts.resolveDataFile(
                SQL_DIR, schemaIdxSql);

ScriptUtils.executeSqlScript(
        conn,
        new EncodedResource(
                new FileSystemResource(schemaIdxFile),
                StandardCharsets.UTF_8),
        false,
        false,
        ScriptUtils.DEFAULT_COMMENT_PREFIXES,
        ScriptUtils.EOF_STATEMENT_SEPARATOR,
        ScriptUtils.DEFAULT_BLOCK_COMMENT_START_DELIMITER,
        ScriptUtils.DEFAULT_BLOCK_COMMENT_END_DELIMITER);
```

关键原因：

- `schema-views-and-functions.sql` 包含 PostgreSQL `$$...$$` 函数体。
- Spring 默认使用分号分割会把函数体内的变量声明和语句拆开。
- `EOF_STATEMENT_SEPARATOR` 让整份 SQL 文件作为一次 JDBC Statement 执行。
- 这与修改前“读取整个文件后一次 `Statement.execute(sql)`”的语义一致。

动态数值参数：

```java
protected void executeQuery(
        String query, long parameter, String logQuery) {
    try (Connection conn = DriverManager.getConnection(
                dbUrl, dbUserName, dbPassword);
         PreparedStatement statement =
                conn.prepareStatement(query)) {
        statement.setLong(1, parameter);
        statement.execute();
    }
}
```

校验核心：

```java
private String getValidatedServerName(
        HttpServletRequest request) {
    String serverName = request.getServerName();
    if (serverName == null
            || serverName.isBlank()
            || serverName.length() > 253) {
        throw new IllegalArgumentException(
                "Invalid server name");
    }
    if (InetAddresses.isInetAddress(serverName)) {
        return serverName;
    }
    String asciiName =
            IDN.toASCII(
                    serverName,
                    IDN.USE_STD3_ASCII_RULES);
    if (asciiName.length() > 253
            || asciiName.startsWith(".")
            || asciiName.endsWith(".")) {
        throw new IllegalArgumentException(
                "Invalid server name");
    }
    for (String label : asciiName.split("\\.")) {
        if (label.isEmpty()
                || label.length() > 63
                || label.startsWith("-")
                || label.endsWith("-")) {
            throw new IllegalArgumentException(
                    "Invalid server name");
        }
    }
    return asciiName;
}
```

影响：

- IP 地址和标准域名正常。
- 国际化域名会转换为 IDN ASCII。
- 尾随点 FQDN、非法下划线域名、异常 Host 注入字符会被拒绝。
- 只影响“生成 Edge 安装说明”，不影响已经运行的 Edge 连接。
- 使用反向代理时需要确认 `request.getServerName()` 得到的是合法外部域名。

文件：

`DefaultEdgeUpgradeInstructionsService.java`

版本约束：

```java
private static final int MAX_UPGRADE_VERSIONS = 1000;
private static final Pattern EDGE_ATTRIBUTE_VERSION_PATTERN =
        Pattern.compile("^V_\\d+(?:_\\d+){1,3}$");
private static final Pattern EDGE_VERSION_PATTERN =
        Pattern.compile("^\\d+(?:\\.\\d+){1,3}$");
```

映射更新：

```java
public void updateInstructionMap(
        Map<String, EdgeUpgradeInfo> map) {
    if (map == null
            || map.size() > MAX_UPGRADE_VERSIONS) {
        throw new IllegalArgumentException(
                "Invalid Edge upgrade version mapping");
    }
    Map<String, EdgeUpgradeInfo> validatedMap =
            new HashMap<>();
    for (Map.Entry<String, EdgeUpgradeInfo> entry
            : map.entrySet()) {
        validateDocsVersion(entry.getKey());
        EdgeUpgradeInfo info = entry.getValue();
        if (info == null) {
            throw new IllegalArgumentException(
                    "Edge upgrade information "
                            + "must not be null");
        }
        if (info.getNextEdgeVersion() != null) {
            validateDocsVersion(
                    info.getNextEdgeVersion());
        }
        validatedMap.put(entry.getKey(), info);
    }
    upgradeVersionHashMap.clear();
    upgradeVersionHashMap.putAll(validatedMap);
}
```

循环和断链：

```java
Set<String> visitedVersions = new HashSet<>();

while (edgeUpgradeInfo.getNextEdgeVersion() != null
        && !tbVersion.equals(currentEdgeVersion)) {
    ensureNoUpgradeCycle(
            visitedVersions, currentEdgeVersion);
    // 生成当前版本升级说明
    currentEdgeVersion =
            edgeUpgradeInfo.getNextEdgeVersion();
    if (tbVersion.equals(currentEdgeVersion)) {
        break;
    }
    edgeUpgradeInfo =
            upgradeVersionHashMap.get(
                    currentEdgeVersion);
    if (edgeUpgradeInfo == null) {
        throw new IllegalStateException(
                "Incomplete Edge upgrade "
                        + "version mapping");
    }
}
```

影响：

- `3.6.0`、`4.1.0`、`4.1.0.1` 等格式允许。
- 包含 HTML、脚本、字母后缀或超过四段的版本会拒绝。
- Edge 属性版本必须类似 `V_3_6_0`。
- 循环映射不再导致死循环。
- 映射更新使用 `clear + putAll`；并发读取存在极短的空窗口，最坏情况是临时显示“无升级指令”，不影响 Edge 数据同步。后续可改成不可变 Map 原子替换进一步消除此窗口。

## 6. 性能影响

| 位置 | 是否在热路径 | 性能判断 |
|---|---|---|
| HTTP `produces` 和 `nosniff` | 每个 HTTP 请求 | 仅响应元数据，影响可忽略 |
| `SecurePathUtils.toRealPath` | 启动、安装、升级、读取证书 | 有文件系统调用，但不在遥测热路径 |
| Trendz/2FA/通知保存后回读 | 管理配置保存 | 多一次数据库读取，频率极低 |
| Edge 升级映射校验 | 周期更新或请求指令 | 最多 1000 项，影响很低 |
| Markdown Sanitizer | 打开 Edge 指令页面 | 仅前端页面渲染，影响很低 |
| 遥测、规则引擎、Actor、DAO | 未修改 | 无直接性能影响 |

结论：预计不会影响设备上报吞吐、规则引擎吞吐或时序数据库日常读写性能。
