# 金仓适配 AI 使用说明

> 分支：`feature/kingbase-V008R006C009B0014-pg-oracle`　技术细节见 `docs/kingbase-pg-oracle.md`

## 结论

ThingsBoard 已支持金仓 V8 的 **pg** 和 **oracle** 两种兼容模式，**业务代码零改动，对现有 PostgreSQL 部署零影响**。
pg 模式直接可用；oracle 模式只需连接串加一个参数，安装时自动打一个小补丁。

## 怎么用 AI 做的

| 步骤 | 人做什么 | AI 做什么 |
|---|---|---|
| 1. 摸底 | 准备金仓 pg / oracle 两套库 | 让全量 950 个 dao 测试分别跑在 PG 和两种金仓模式上，自动比对失败清单 |
| 2. 定位 | 确认方向 | 从 2740 条报错里归纳出唯一根因：oracle 模式下 3 参 `concat` 被金仓 `sys` 函数遮蔽 |
| 3. 修复 | 审核方案 | 写补丁脚本（3 行 SQL）+ 安装期自动探测、权限检查、复验逻辑 + 9 个单测 |
| 4. 验证 | 在 71 环境实跑 | 回归全量用例，失败清单与 PG 逐项一致；编写部署文档和 docker-compose |

**人负责判断和拍板，AI 负责跑测试、查原因、写代码和文档。**
